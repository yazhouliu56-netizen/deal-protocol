## P1 高价值（影响核心漏斗）

| # | 项 | 说明 | 状态 |
|---|----|------|------|
| 1 | 发布需求 CTA 强化 | 首页「发出你的需求」目前为普通宽按钮；发布是全产品核心动作，应收敛为视觉主 CTA（大按钮 + 渐变光效 + 常驻悬浮），并带表单引导（时间/地点/品类快捷选择，现仅一句自由输入） | ✅ 渐变主 CTA + 入场动画 + 副文案引导（WaveFeed.tsx） |
| 2 | 竞价卡与雷达流解耦 | `公开竞价` 演示卡混在雷达 Feed 同级顶部，用户分不清可点性/数据归属；收进卡片化 section 或加「演示」角标弱化 | ✅ 虚线玻璃卡 + 「演示沙盒 / 无真实资金」标识，图标去 glow 降权（BiddingSandboxCard.tsx） |
| 3 | 空态引导链 | 首页空雷达有文案无高亮引导；首次进入应高亮发布 CTA + 步骤提示，拉新转化 | ✅ 三步引导条（①发出需求→②接单→③履约）+ localStorage 记忆，「知道了」后不再显示（WaveFeed.tsx） |
