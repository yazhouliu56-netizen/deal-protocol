# ADR-0004: 真实地图选型（P3）与 3D 分层策略
日期：2026-08-09
状态：Accepted

## Context

P3 需要真实地图底图。约束与目标：1) 完全免费、无 API Key；2) 本地开发，
100 人内试点，上线时才备服务器资源；3) 用户期望「泡在地图里找店/找人」，
初期不做游戏效果，但要有 3D 真实感与层次感；4) 现有 S1 CSS 热力图可作降级
兜底；5) 国内部署场景，OSM 官方瓦片在大陆被屏蔽（GreatFire 实测）且官方
瓦片服务有使用政策（付费不可用、需 Referer/attribution、无 SLA、可随时断供）。

## Decision

- **地图引擎：MapLibre GL JS + OpenFreeMap 公共矢量实例**（免费、无 Key、
  无注册、无请求上限；无 SLA 但百人级试点可接受）。原生 WebGL 支持：
  倾斜视角、建筑 3D 立体（层次感来源）、主题切换与镜头飞行（后续用）。
- **初期功能集收敛**：仅「底图 + 3D 透视层次（默认带倾角、建筑高度量）+
  现有数据点（需求/邻居 lat/lng）渲染 + 点击聚焦」。不做镜头剧情、
  动画效果、音效、暗色主题等游戏化叠加。
- **架构留口**：地图视图与管理游戏化后置为独立叠加层（动画/镜头/音效
  通过接口注入，不进核心渲染路径）；瓦片源 URL 可配置切换
  （→ 上线时换自建 TileServer / PMTiles 或商用源）。
- **降级保留**：沿用 deviceMemory 降级链，低配环境回退现有 CSS 热力图。
- **内容密度另项推进**（演示数据冷启动），不阻塞本 ADR。

## Alternatives Rejected

- **Leaflet + OSM 官方瓦片**（原计划）：无 3D 能力（不满足需求），且
  tile.openstreetmap.org 大陆被屏蔽、政策限制多。
- **高德 / 腾讯瓦片**：需 API Key 非免费、商用合规风险，与「完全免费」
  目标冲突。
- **地图 + 完整游戏化一期做齐**：初期即上镜头/音效/动效 = 过度工程，
  收益与工作量不成比例。

## Consequences

- 初期不存在工程：单层渲染（map + markers），游戏化层后置挂接口。
- 包体积增大（MapLibre 核心数百 KB），需按需动态引入（仅地图页加载）。
- 瓦片源切换只改 style URL 配置，不影响数据层；未来自建/商源无缝迁移。
- 与 S2「热力图/附近」的 lat/lng 数据结构直接复用，无数据迁移成本。
