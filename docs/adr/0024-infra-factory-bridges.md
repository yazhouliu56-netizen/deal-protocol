## Decision

- **A 传输形态（R-0928-11）**：纸条照收、墙不砌。六接口 Payload 全收为 TypeScript 类型＋函数签名，走内调；真拆服务日再套 HTTP，字段不动。HTTP 边界只留给外部（第三方硬件/监管），不在六口之内。
- **B 网格与锁单（R-0928-12）**：H3 转 backlog（触发：撮合 P95 连续超标或量级上台阶）；`lock_token` 两段锁不要（CAS＋互刷 R1 零超卖实证在先）；半径/时段/缓冲参数照收为配置。预约单是大头（双轨既定）：三个增量——①`BOOKED` 前态（增补）；②`(供给, 时段)`唯一约束＋重复发布判供给方担责（防＞断）；③爽约罚则档（接 `cancellationTiers`，总则"谁的责任谁赔"，认定 GPS 到达打卡＋时限）；时段系数进弹药表。体验链复用 push/通知/GuardStrip。
- **C 资金方向（R-0928-13 前半）**：全额支付＋托管（单冻结位 HELD，不另设风险池）；第三方持牌承保、保费含总额内（R-0928-05/06）。
- **D 录音（R-0928-08/09/10，已裁，引用执行）**：三档（A 授权后不可逆 / B 自保按钮 / C 禁区）；留存 A30/B7/纠纷随案/TAMPER90，只存线上加密、立案才解密；悬浮对称（SOS 右下、一键录音左下，GuardStrip 主位＋SOS 面板备位）。
- **E 证据包**：零新表，映射既有司法导出包；解密原话进包前脱敏，仲裁员"展开"记审计。
- **F 分账对应（R-0928-13 后半）**：冻结＝全额 HELD；分账单改名对齐（`routing_splits`/`account_type`）；`INSURANCE_PREMIUM` 位先占位缺省 0，E 组费率回来填数；自动划扣＝指令执行态直付保险公司（不沉淀，V4 同制）。
- **G 性能叙事（R-0928-14）**：加注——"无复杂 if-else"改为"热路径无外部 IO 阻塞"；"毫秒级"指装配与执行，上限看 DB/LLM（R-0928-03 同款注脚）。

## Alternatives Rejected

- 六口砌 HTTP 墙：否决（同机开销＋故障点，与毫秒叙事自悖）。
- H3 现在引 / lock_token 现在上：否决（无瓶颈实证、无超卖实证，提前交税）。
- 风险押金另冻一笔：否决（全额已含，重复收费）。
- 用户设备存录音：否决（可删可改＋丢机泄露＋遗忘权删不干净）。
- 缺口现在开工：全部否决（RAG-SOP/H3/公式 parser/真 SDUI 无触发条件）。
