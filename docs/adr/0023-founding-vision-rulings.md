## Decision（裁决 ID 永久有效，同事实模式可引用）

- **R-0928-01 AI 划扣**：纲领"AI 大法官直接调用金融 API 划扣"作废。维持铁律"AI 绝不碰钱 / LLM 仅 Advisory"与现行议会制 + 确定性执行（d15bc86）。引用判例：既往资金安全裁决（先行赔付砍掉、V4 反二清）。
- **R-0928-02 强制录音**：纲领"强制不可逆静默录音"降格为"授权后节点自动触发"（进高危节点 + 已授权 → 自动开，可审计可关）。依据 #8 隐私血液与合规/上架风险。
- **R-0928-03 五秒量产**：纲领"5 秒量产上线"加注——秒级指装配（配置生成）速度，量产对象是弹药配置，上线照走门禁（T2/手工 DDL/双绿 CI，一步不让）。
- **R-0928-04 技术选型**：纲领点名（H3/S2、Temporal/Go-Workflow、GPT-4o/Gemini 1.5 Pro、应用商店热更新）保义去名，不换栈（Next+PWA+自研状态机+Gateway 能力对等覆盖）；缺口（RAG-SOP/H3/公式 parser/真 SDUI）留 backlog，触发条件另议。

## Alternatives Rejected

- 恢复纲领原文（LLM 直划扣 / 强制不可逆 / 门禁让路 / 启动换栈）：全部否决，理由见四条权衡（监管风险 / 合规上架风险 / 质量红线 / 重写成本）。
- 现在开工缺口：否决，无触发条件（规模动机/商务 key/法务输入均缺席）。
