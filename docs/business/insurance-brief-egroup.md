# E 组任务书：第三方保险对接（2026-09-28 用户裁决 R-0928-05/06/07）

## 已裁决（不动）

- **三层结构**：基础险（服务者人身意外，出门到回家全程）＋ 随单险（入户专属：第三者责任＋用户财产损失）一起上；提示层（用户贵重物品/人身）顺手做，只提示不代售。
- **出资**：平台不出。基础险由师傅自行购买，**无有效保单接不了单**（接单门禁）；随单险含订单总额内，自动划扣。
- **承保**：第三方持牌机构，平台只代收代付。

## 商务谈判点（E 组填空，具体按对接机构定）

1. 持牌机构名称与资质（保险许可证号留档）。
2. 基础险：保障范围（意外身故/伤残/医疗）、保额、保费（目标：按天计价，参考业界 0.2–3 元/天档）、生效规则（购买当日生效？T+1？）、 regions。
3. 随单险：保障范围（第三者人身/财产、用户财产损失上限）、费率（总额占比或按单固定）、生效规则（接单即生效，跟单走）。
4. 理赔 API：报案接口、状态查询接口、SLA（报案响应时限、赔付时限）；无 API 则先人工通道 + 后补。
5. 等待期 / 免赔：意外险不得设疾病式等待期；意外医疗免赔额与给付比例逐项列明。
6. 保单数据接口：平台验单用（接单门禁查验保单有效期），批量接口或单单查询。

## 合规红线（谈判底线，让步即上报）

1. 平台无保险牌照：**只代收代付，不代售**；保费从总额切出直付保险公司，不在平台账上过夜（V4 反二清同样适用）。
2. 故意犯罪、投保前已患、等待期内出险等除外责任逐项书面确认。
3. 告知义务：下单页一屏讲清保什么、保额、免赔、找谁理赔（骑手"首单险"不知情扣费的坑不重演）。
4. 用户隐私：保单/理赔数据最小够用；信用展示保险信息须经本人授权（2026-08 家政 19 条口径）。
